## 运行实验

需要 Python 3.12（本次测试为 3.12.14）。实验和独立核验仅使用标准库，不需要 pip 安装计算包、联网或下载外部数据。输入与规则均在脚本中，无随机种子。

在 PowerShell 中进入**本提交文件夹**，运行：

```powershell
python --version
python -X utf8 ".\AIS实验_一键复现.py" --output-dir "复现输出_新一次"
```

`python` 应指向已安装的 Python 解释器。输出目录必须尚不存在；再次运行请换一个名称。请勿使用 `-O` 或 `-OO`，它们会关闭实验断言。保留 `.report_build` 子目录，其中有三个独立核验脚本。

入口会复制脚本到新目录，重新计算，并保存结果 JSON、六份日志和 `复现核对记录.json`。成功时显示三行 `PASS`；记录中的 `status` 应为 `passed`，所有检查应通过。

| 表 5-1 | 自由／每格正漏计 A／允许零漏计的范围 B：60、30、15 分钟下均为 4、6、4 船时 |
